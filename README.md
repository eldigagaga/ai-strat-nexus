# AI Marketing Hub

Vytvoř moderní, responzivní webovou stránku jako podpůrný studijní portál pro vysokoškolský předmět:

Název předmětu:
Umělá inteligence v marketingu a komunikaci firem (3MG303)
Vysoká škola ekonomická v Praze (VŠE)

🎯 CÍL WEBU

Web slouží jako praktický a přehledný hub pro studenty – najdou zde:

 shrnutí přednášek

 výukové materiály

 videa

 AI nástroje

 možnost interakce s AI (avatar + chatbot)

Styl: moderní, čistý, lehce futuristický, ale stále akademický.
Tone: praktický, srozumitelný, „méně teorie, víc praxe“.

🎨 DESIGN & STYL

 Vycházej z přiloženého vizuálního stylu (tmavé pozadí + kontrastní akcenty)

 Barvy:

 tmavě modrá / tmavě šedá (background)

 bílá (text)

 oranžová (CTA tlačítka)

 jemná světle modrá / tyrkysová (doplňkové prvky)

 Styl karet (cards), jemné stíny, zaoblené rohy

 Používej moderní font (např. Inter / Poppins)

 UX: přehledné sekce, dostatek whitespace
